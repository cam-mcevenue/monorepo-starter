### Spec a feature

**Turn an idea into something buildable.** The playbook ends at a published spec or ticket, or at a hand-over into **Build a feature** in this session.

1. Grill the idea with **grill-with-docs**, however small it is. When a question needs running code to settle, offer a **prototype** inline, then return to the grilling with its answer.
2. Size it from the grilling, and recommend one path:
   - **Fits in one ticket:** offer the operator a choice. Either publish a single ticket with **to-tickets** from the conversation, or build it now: run **Build a feature** in this session with the grilling as its spec.
   - **Bigger:** write the spec with **to-spec**. Then offer **to-tickets** now, or leave the split to **Build a feature**.

**Reply:** the link to the spec or ticket, and the ADRs and glossary terms created.
